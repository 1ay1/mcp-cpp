# mcp-cpp — concurrency allowlist (checked by agentty's concurrency_banlist_mcp).
#
# mcp-cpp starts no threads: background work, deadlines and parallel scans go
# through mcp::Runtime / tools::Executor, which the host installs. Two kinds of
# entry remain, and nothing else may appear:
#
#   1. runtime.hpp — the standalone fallback (std::jthread), the ONE place the
#      library may name a thread. agentty replaces it at startup.
#   2. locks and atomics that protect a structure's own state (the engine's
#      waiter table, a transport's write side, a cache, a work cursor). They
#      make a type safe to call from the host's threads; they run nothing.
#
# std::async(launch::deferred) in rpc.hpp starts no thread: it is the lazy
# decode step of a typed request.
